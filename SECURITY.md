# Безопасность выпуска VANIOR PRINT

VANIOR PRINT собирается как обычное 64-разрядное Windows-приложение в режиме
PyInstaller `onedir`. Сборка не требует прав администратора, не использует UPX,
не устанавливает службы или драйверы и не добавляет исключения антивируса.
Установщик содержит страницу лицензии и памятку, сведения об издателе и ссылки
на сайт проекта. Для каждого релиза создаются SHA-256 и JSON-манифест состава.

## Цифровая подпись

Без доверенного Authenticode-сертификата нельзя гарантированно убрать
предупреждение SmartScreen у нового малоизвестного приложения. Скрипт сборки
поддерживает подпись основного EXE и установщика одним сертификатом из хранилища
`CurrentUser\\My`, а также временную метку:

```powershell
$env:VANIOR_SIGNING_CERT_THUMBPRINT = "ОТПЕЧАТОК_СЕРТИФИКАТА"
.\packaging\build_installer.ps1 -PythonExecutable .\.venv\Scripts\python.exe
```

Имя издателя в установщике должно совпадать с удостоверенной личностью
в сертификате. Для всех выпусков следует использовать одну и ту же подпись.

## Ложное срабатывание

Не следует просить пользователя выключать защиту или добавлять папку в
исключения. Если конкретный релиз определяется как вредоносный, разработчик
проверяет его локально, сверяет SHA-256 и отправляет именно этот файл как ложное
срабатывание через официальный портал Microsoft:
https://www.microsoft.com/wdsi/filesubmission

Документация Microsoft о репутации SmartScreen:
https://learn.microsoft.com/windows/apps/package-and-deploy/smartscreen-reputation
