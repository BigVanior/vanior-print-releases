VANIOR PRINT 0.6.6 — памятка тестировщику Public Beta

Приложение самостоятельно анализирует, восстанавливает и нарезает модель,
создаёт проверенный .gcode.3mf и при желании отправляет его напрямую на принтер.
Bambu Studio, Python и облачная авторизация не требуются.

Проверенная область этой версии:
- Windows 10/11 x64;
- Bambu Lab P1S, сопло 0,4 мм;
- одноцветные PLA и PETG;
- STL/3MF с одной печатаемой моделью.

Перед первым тестом:
1. Используйте тестовую копию модели и свободную чистую пластину.
2. Проверьте материал, сопло, тип пластины, ориентацию и все слои предпросмотра.
3. Не печатайте ответственные детали и не оставляйте первый запуск без наблюдения.
4. Для прямой отправки включите локальный режим принтера, вставьте microSD-карту,
   укажите IP, серийный номер и LAN access code, затем закрепите показанные
   сертификаты только после сверки с выбранным устройством.

Код доступа не сохраняется. Сертификаты, IP и серийный номер хранятся локально.
Перед отправкой VANIOR PRINT повторно проверяет 3MF, сопло и состояние принтера,
а запуск выполняет только после отдельного подтверждения.

Если результат выглядит неправильно, не запускайте печать. Создайте
диагностический ZIP в настройках и приложите скриншот, исходную тестовую модель,
выбранный профиль и точный текст ошибки.
