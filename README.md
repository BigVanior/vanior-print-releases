# VANIOR PRINT 0.6.6 Public Beta

VANIOR PRINT — самостоятельное Windows-приложение для локальной подготовки
одноцветных моделей к печати. Оно анализирует и восстанавливает STL/3MF,
выбирает ориентацию и поддержки, нарезает модель собственным движком VANIOR
Slice, проверяет G-code, создаёт `.gcode.3mf` и может отправить его напрямую на
принтер в локальной сети. Bambu Studio, Python и облачная учётная запись для
работы установленного приложения не нужны.

## Проверенная область Public Beta

- Windows 10/11 x64;
- Bambu Lab P1S;
- сопло 0,4 мм;
- одноцветная печать PLA или PETG;
- входные STL и 3MF с одной печатаемой моделью;
- сравнение вариантов без поддержек, с обычными и древовидными поддержками;
- локальная отправка проверенного `.gcode.3mf` через FTPS и MQTT/TLS.

Многоцветная печать, другие принтеры, сопла и материалы намеренно блокируются,
пока для них нет отдельного проверенного профиля. Движок имеет статус
engineering preview: перед первым физическим тестом каждого профиля необходимо
просмотреть все слои, а первые задания запускать под наблюдением. Приложение не
предназначено для ответственных деталей, отказ которых может причинить вред.

## Прямая печать

На принтере нужно включить локальный режим, установить microSD-карту и узнать
IP-адрес, серийный номер и LAN access code. В разделе «Принтер и локальная
печать» сначала выполняется проверка сертификатов принтера, затем пользователь
явно закрепляет их. Код доступа хранится только в памяти процесса.

Перед каждой отправкой приложение повторно проверяет контейнер, контрольные
суммы, назначение P1S, сопло 0,4 мм, состояние принтера, наличие выбранного AMS
и точный размер загруженного файла. Запуск требует отдельного подтверждения.
Подробности: [docs/DIRECT_PRINTING_RU.md](docs/DIRECT_PRINTING_RU.md).

## Данные и сеть

Анализ и нарезка выполняются локально. Сеть используется только для прямого
соединения с выбранным пользователем принтером и для необязательной синхронизации
PrintDNA, которая выключена по умолчанию. Политика конфиденциальности находится
в [docs/PRIVACY_POLICY_RU.md](docs/PRIVACY_POLICY_RU.md), условия использования —
в [docs/TERMS_OF_USE_RU.md](docs/TERMS_OF_USE_RU.md).

## Разработка и проверки

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\python.exe -m pytest -q -p no:cacheprovider
.\.venv\Scripts\python.exe -m ruff check src tests packaging\inventory_licenses.py
```

Сборка обычного обновляемого установщика:

```powershell
.\packaging\build_latest_installer.ps1
```

Установщик использует постоянный `AppId`, поэтому запуск новой версии обновляет
существующую установку без предварительного удаления. Без доверенной
Authenticode-подписи Windows SmartScreen всё равно может показывать предупреждение;
самоподписанный сертификат это не устраняет. Скрипт сборки умеет подписать EXE,
если задан `VANIOR_SIGNING_CERT_THUMBPRINT`.
