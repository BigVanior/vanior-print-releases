# Условия использования VANIOR PRINT Public Beta

Дата редакции: 10 сентября 2026 года.

Правообладатель предоставляет пользователю ограниченное, неисключительное право
установить и использовать VANIOR PRINT Public Beta при соблюдении этих условий.
Права на сторонние компоненты определяются только их собственными лицензиями.

VANIOR PRINT предназначен для подготовки файлов 3D-печати. Пользователь обязан
до запуска проверить принтер, сопло, материал, пластину, расположение модели,
поддержки и каждый слой итоговой траектории. Первая печать нового профиля должна
проходить под наблюдением.

Public Beta может содержать ошибки. Результаты нельзя использовать для деталей,
отказ которых способен причинить вред человеку, животному или имуществу, без
независимой инженерной проверки. Приложение не заменяет инструкции производителя
принтера, материала и требования пожарной безопасности.

Прямая отправка использует локальные интерфейсы совместимого принтера. Их
поведение может измениться после обновления прошивки. Пользователь подтверждает,
что управляет выбранным устройством и имеет право отправлять ему задания.

Права на собственный код VANIOR PRINT принадлежат Ivan Valevich. Сторонние
компоненты распространяются по лицензиям из THIRD_PARTY_NOTICES_RU.txt. VANIOR
PRINT не включает Bambu Studio и не аффилирован с Bambu Lab; товарные знаки
используются только для описания совместимости.

Программное обеспечение предоставляется «как есть» в пределах, разрешённых
применимым законодательством. Этот текст не является юридическим заключением;
перед коммерческой публикацией требуется проверка условий для страны продавца и
рынков распространения.
