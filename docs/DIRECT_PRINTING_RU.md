# Прямая локальная печать VANIOR PRINT

## Что делает приложение

VANIOR PRINT версии 0.6.6 выполняет весь программный цикл самостоятельно:

1. читает STL или одноцветный 3MF;
2. проверяет и безопасно ремонтирует сетку;
3. выбирает ориентацию и тип поддержек;
4. строит траектории VANIOR Slice;
5. проверяет координаты, экструзию и объёмный поток;
6. создаёт печатный `.gcode.3mf`;
7. загружает его непосредственно на P1S и отправляет команду запуска.

Bambu Studio, его network plugin и облачная учётная запись не участвуют. Названия
полей `BambuStudio:*`, которые могут встречаться в 3MF, принадлежат аппаратному
диалекту файла P1S и не означают запуск сторонней программы.

## Требования

- Bambu Lab P1S и сопло 0,4 мм;
- PLA или PETG и одноцветное задание;
- microSD-карта в принтере с доступным местом;
- компьютер и принтер в одной доверенной локальной сети;
- включённый на принтере LAN Only/Developer Mode;
- локальный IPv4, серийный номер и LAN access code с экрана принтера.

VANIOR PRINT намеренно не принимает публичные IP-адреса и не выполняет облачную
отправку.

## Первое подключение

1. Откройте раздел «Принтер и локальная печать».
2. Введите IP, серийный номер и LAN access code.
3. Выберите внешнюю катушку либо фактический слот AMS A1–A4.
4. Нажмите «Проверить и доверять принтеру».
5. Сверьте IP и серийный номер в окне подтверждения и закрепите сертификаты.

Приложение сохраняет только IP, серийный номер, выбранные опции и SHA-256
сертификатов. LAN access code не записывается на диск. Если сертификат, IP или
серийный номер изменился, отправка блокируется до повторной проверки.

## Отправка задания

После завершения оптимизации откройте «Предпросмотр» и нажмите «Отправить на
принтер». Перед запуском приложение:

- проверит манифест и контрольные суммы файла;
- подтвердит, что задание предназначено для P1S/0,4 мм;
- убедится, что принтер не занят;
- загрузит файл по FTPS и сверит его размер;
- покажет отдельное окно подтверждения физического запуска;
- отправит команду по MQTT/TLS и дождётся ответа.

Если ответ после отправки команды не получен, повторно нажимать кнопку нельзя до
проверки экрана принтера: первая команда уже могла быть принята.

## Граница текущей версии

Сетевой транспорт реализован без стороннего приложения, но зависит от локального
протокола прошивки самого принтера. Производитель может изменить этот протокол в
новой прошивке. До физических контрольных прогонов v0.6 остаётся публичной бета-
версией: проверяйте слои, наблюдайте первый слой и не оставляйте первый запуск
нового профиля без присмотра.
