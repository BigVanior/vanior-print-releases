# Архив: интерфейс VANIOR PRINT v3.2.0

> Этот документ описывает старый внешний контур до версии 0.6 и сохранён только
> для истории. Текущий релиз использует VANIOR Slice; актуальные сведения — в
> корневом README и `INDEPENDENT_ENGINE_RU.md`.

## Несколько моделей в одном STL или 3MF

Если выбранная пластина 3MF содержит несколько печатаемых объектов или STL
содержит несколько значимых раздельных тел, приложение
автоматически анализирует каждый объект отдельно. Для каждой модели независимо
выбираются назначение, высота слоя, стенки, заполнение, скорости, локальные
диапазоны и supports. Для 3MF исходное расположение объектов не меняется; тела
STL совместно центрируются на столе с сохранением взаимного расположения. В результате
показывается отдельная строка параметров для каждой модели, а один итоговый 3MF
содержит все объектные настройки и готовый G-code.

## Единое рабочее пространство

Установленная версия использует `S:\VANIOR PRINT`. При выборе STL или 3MF файл
безопасно переносится в `1. Загружаемые файлы`: сначала создаётся и проверяется
копия на S:, затем исходный файл удаляется. Один готовый 3MF всегда публикуется
в `2. Готов к печати`, независимо от первоначального расположения модели.

Полные архивы для отката сохраняются в `3. Бэкап приложения`. PrintDNA,
фотографии дефектов и переносимый журнал событий обучения хранятся в
`4. Файлы для обучения`, поэтому они не привязаны к конкретной версии EXE.

## Запуск

Откройте папку Windows-сборки и дважды щёлкните `VANIOR PRINT.exe`.
Приложение переносимое: содержимое подпапки `_internal` должно оставаться рядом с exe.
Bambu Studio устанавливается отдельно и обычно определяется автоматически.

Окно прокручивается целиком по вертикали. После завершения приложение показывает
карточку результата, не уменьшая высоту полей настроек; на небольшом экране для
возврата к верхним параметрам используйте полосу прокрутки справа.

## Обычная обработка

1. Перетащите STL или 3MF в поле **Модель** либо нажмите **Обзор**.
2. Оставьте действие **Полная оптимизация и один готовый 3MF**.
3. Выберите **Приоритет**: максимальное качество, баланс либо быстрая печать.
4. Оставьте **Назначение → Определить автоматически** либо вручную укажите
   декоративную модель или нагруженную деталь.
5. Проверьте принтер, сопло, тип пластины и материал. Доступны
   Bambu Lab P1S, сопло 0,4 мм, Textured PEI, PLA и PETG.
6. Добавлять профильный 3MF не нужно. Приложение само соберёт чистый одноцветный
   профиль из официальных файлов установленного Bambu Studio.
7. Путь результата выбирать не нужно: проект и итоговый 3MF всегда сохраняются
   в `S:\VANIOR PRINT\2. Готов к печати`, старые результаты не перезаписываются.
8. Нажмите **Оптимизировать и нарезать**.
9. После завершения нажмите **Открыть 3MF в Bambu Studio**. Проверьте превью
   пластины и нажмите печать в Bambu Studio.

Назначение не переключает качество видимых поверхностей: декоративная и нагруженная
модели получают одинаковые верхние слои, скорости наружных поверхностей, шов и
интерфейс поддержек. Для нагруженной детали приложение дополнительно увеличивает
стенки, нижнюю оболочку и заполнение.

Если модель небольшая (до 50 мм) и преимущественно криволинейная, приложение
автоматически покажет в результате строку **Поверхность: высокая детализация малой
криволинейной модели**. Для неё активируются более тонкий слой, замедление мелких
контуров, умеренная температура PLA и сглаженный задний шов. Дополнительного
переключателя пользователю не требуется.

## Точный поиск минимального времени

На странице **Оптимизация** по умолчанию включён переключатель **Точный поиск
минимального времени по реальным нарезкам**. Приложение сначала создаёт эталон
качества, затем допускает только безопасные изменения внутренних параметров и
передаёт кандидатов в установленный Bambu Studio. Побеждает минимальное фактическое
время среди вариантов, прошедших пороги качества и надёжности без предупреждений.

В результате показываются исходное и выбранное время, процент экономии, оценки
качества и надёжности и применённые изменения. Отключите поиск, если нужна только
одна эталонная нарезка. При включённых ручных параметрах перебор автоматически не
меняет их.

## Surface Intelligence

После анализа откройте карточку **Surface Intelligence**. Она показывает, какая
доля модели распознана как верхняя поверхность, видимая стенка, криволинейная
область, кандидат точной посадки, контакт со столом или контакт с поддержками.
Решения карты автоматически применяются при оптимизации и записываются в манифест.

Классификация v1 основана на геометрии и не выдаёт предположение за достоверное
назначение. Пользовательские параметры на странице настроек имеют приоритет.

## PrintDNA

После физической печати откройте вкладку **PrintDNA**, выберите проект из истории,
поставьте оценку и отметьте обнаруженные дефекты. Оценка сохраняется отдельно для
связки принтера, диаметра сопла и материала. Следующая оптимизация автоматически
получит ограниченные поправки, а результат покажет количество учтённых отпечатков.

Данные находятся только в локальной папке приложения. Хорошая печать без дефектов
не вызывает дрейфа параметров, а ручные настройки всегда применяются последними.

В результате новая папка содержит ровно один файл `ИмяМодели_готово.3mf`. Внутри
него находятся оптимизированная модель, выбранные настройки и встроенный G-code.
Варианты поддержек и диагностические файлы создаются только во временной папке и
удаляются после проверки. Если проверка не завершилась, итоговая папка не публикуется.

## Только проверка

Выберите **Только проверить модель**, если нужна диагностика без записи результата.
Для 3MF приложение извлекает только печатные объекты выбранной пластины во временную
папку. Исходный проект не изменяется.

## Прямая нарезка 3MF

Режим **Нарезать исходный 3MF без исправления** предназначен для проекта, настройки
и геометрию которого нужно сохранить. Он не выполняет автоматический ремонт и
доступен только для 3MF. Используйте его осознанно, если полная оптимизация сообщает,
что сетке требуется ручное исправление.

## Отмена и ошибки

Кнопка **Отменить** останавливает публикацию результата и завершает запущенный
слайсер. Частичная папка может остаться для диагностики, но её файлы не считаются
готовыми к печати. При закрытии окна во время работы приложение сначала выполняет
безопасную отмену.

Если Bambu Studio не найден, укажите вручную:
`C:\Program Files\Bambu Studio\bambu-studio.exe`.
