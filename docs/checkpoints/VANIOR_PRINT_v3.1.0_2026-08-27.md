# VANIOR PRINT v3.1.0 — единое рабочее пространство

Дата: 2026-08-27.

## Размещение

Рабочая версия установлена в `S:\VANIOR PRINT` и использует четыре постоянные
пользовательские папки:

1. `1. Загружаемые файлы` — выбранные STL/3MF.
2. `2. Готов к печати` — проекты и один итоговый 3MF.
3. `3. Бэкап приложения` — версии для отката и данные восстановления.
4. `4. Файлы для обучения` — история, PrintDNA и общий журнал обучения.

## Гарантии

- Загруженная модель переносится, а не копируется. Сначала создаётся файл на S:
  и проверяется его SHA-256, только затем удаляется оригинал.
- Если имя занято другим содержимым, используется суффикс хеша; существующий
  файл не перезаписывается.
- Исходный путь модели никогда не участвует в выборе папки результата.
- После оптимизации один проверенный 3MF автоматически публикуется прямо в
  `2. Готов к печати`; внутренние материалы проекта находятся в `Проекты`.
- Формат `vanior-learning-event-v1` не содержит исходной геометрии и личных
  путей. Хранилище одно для всех локальных версий приложения.
- Облачная синхронизация обучения пока отключена и потребует отдельного
  механизма согласия, обезличивания и проверки данных.
