# AI Print Optimizer — контрольная точка v0.6

Дата: 23 августа 2026 года. Статус: воспроизводимый автоматический pipeline.

## Реализовано после v0.5

- единая команда `analyze -> safe repair -> orient -> slice`;
- автоматический выбор одиночного слайсинга или A/B supports по геометрии;
- сравнение `normal(auto)` и `tree(auto)` для отдельного STL через 3MF-профиль;
- разбор `; FEATURE:` и экструзии G-code;
- расчёт отдельной длины и массы supports, support interface и transition;
- исключение ретрактов, возвратов и стационарной продувки из уложенного материала;
- `manifest.json` с версиями, параметрами и SHA-256 входов/артефактов;
- встроенная проверка манифеста и отдельный код завершения при повреждении;
- русификация основных разделов текстового отчёта;
- 26 автоматических тестов.

## Команды

```bash
ai-print-optimizer model.stl \
  --profile-template verified-profile.3mf \
  --pipeline-output NEW_DIRECTORY

ai-print-optimizer model.stl \
  --profile-template verified-profile.3mf \
  --compare-supports NEW_DIRECTORY

ai-print-optimizer NEW_DIRECTORY/manifest.json --verify-manifest
```

- оба варианта успешно нарезаны Bambu Studio 2.8.2.61;
- SHA-256 исходного STL и профиля не изменились;
- манифест повторно проверил 10 файлов без ошибок.

```text

tree(auto):   13447,94 с / 100,62 г / supports 25,78 г
```

Суммарная масса, восстановленная из role-specific G-code, совпала с `total_used_g`
слайсера в пределах округления: `151,80523` против `151,80525 г` и `100,62036`
против `100,62037 г`.

## Ограничения

- масса ролей G-code является вычисленной из экструзии, диаметра и плотности;
- для нескольких материалов учитывается активный слот `M620`, но реальные
  многоматериальные контрольные модели ещё не проверены;
- профиль 3MF пока считается доверенным и не сопоставляется автоматически с
  выбранным в геометрическом анализе материалом;
- физическое качество supports подтверждается только реальной печатью.
