# VANIOR PRINT v3.0.0 — контрольная точка релиза

Дата: 2026-08-27.

## Итог

VANIOR PRINT v3.0.0 подготовлен как полноценный локальный Windows-релиз.
Приложение анализирует STL и 3MF, строит проверяемые варианты печати через
Bambu Studio, выбирает самый быстрый вариант в пределах порогов качества и
надёжности и формирует один итоговый `ready-to-print.3mf` со встроенным G-code.

## Основные возможности v3

- Geometry Intelligence v2: мосты, тонкие стенки и локальные диапазоны
  параметров по высоте модели.
- Functional Intent: автоматическое и ручное назначение детали, включая
  декоративные модели, корпуса, крепления, шестерни, защёлки, сосуды,
  гибкие и силовые детали.
- Support Exit Planning: оценка доступности поддержек и риска следов.
- Quality-Constrained Search v3: реальные контрольные нарезки нескольких
  кандидатов и выбор минимального безопасного времени.
- G-code Audit: проверка объёмного потока, скоростей, ретрактов и коротких слоёв.
- PrintDNA 2: обратная связь по результату печати, фотографии, область и слой
  дефекта, локальная приватная история.
- Проверяемый кэш нарезки, журнал этапов, резервные копии и диагностический ZIP.
- Защита от подмены геометрии по fingerprint и проверка SHA-256 всех артефактов.

## Финальные проверки

- 99 автоматических тестов: успешно.
