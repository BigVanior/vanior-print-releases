# AI Print Optimizer — контрольная точка v1.6.0

Дата: 2026-08-23  
Статус: стабильный локальный релиз `1.6.0`

## Один пользовательский файл

Windows-приложение выполняет анализ, ремонт, ориентацию и реальное сравнение
`none` / `normal` / `tree` во временном каталоге. После выбора стратегии оно
публикует новую папку, содержащую только:

`ИмяИсходнойМодели_готово.3mf`

Внутри 3MF находятся фактическая модель, полный набор выбранных настроек, стратегия
поддержек и G-code пластины. Файл можно открыть в Bambu Studio и отправить на печать.

## Безопасность публикации

- исходный STL/3MF не изменяется;
- существующая папка результата не перезаписывается;
- до публикации проверяется наличие встроенного G-code;
- копия сверяется с проверенным результатом по SHA-256;
- папка появляется атомарно только после полного успеха;
- временные варианты и диагностика удаляются после завершения;
- CLI сохраняет подробный диагностический формат для разработки и проверки manifest.

## Проверки

- компактная выдача содержит ровно один 3MF;
- проект без встроенного G-code блокируется;
- существующая папка не перезаписывается;
- полный набор из 66 автоматических тестов успешно пройден.

Реальная `001.stl` полностью обработана через тот же `JobWorker`, который запускает
GUI. В результате создан единственный `001_готово.3mf` размером 1 614 269 байт;
повторная проверка подтвердила один объект, 63 478 треугольников, выбранный режим
`none`, один `Metadata/plate_1.gcode` и отсутствие ошибок.
