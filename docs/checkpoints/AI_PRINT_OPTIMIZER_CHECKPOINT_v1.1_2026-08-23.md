# AI Print Optimizer — контрольная точка v1.1

Дата: 2026-08-23  
Статус: стабильный локальный релиз `1.1.0`

## Результат

Версия 1.1 исправляет критическую ошибку v1.0, при которой профильный 3MF мог
оказаться самостоятельным результатом с моделью шаблона вместо целевого STL.
Новый pipeline заменяет mesh шаблона целевой геометрией, удаляет остальные
build-items и разрешает публикацию только после проверки результата.

Поддерживаются входы STL и Bambu 3MF. Для 3MF извлекается печатная геометрия
выбранной plate. Pipeline анализирует/ремонтирует/ориентирует модель, применяет
рекомендуемые настройки, независимо слайсит none/normal/tree и помещает в корень:

- `ready-to-print.3mf` — проект с моделью, настройками и встроенным G-code;
- `ready-to-print.gcode` — тот же G-code отдельным файлом;
- `manifest.json` — SHA-256 всех входов и артефактов.

## Защита от подмены

Перед публикацией проверяются:

- ровно один печатаемый объект и ожидаемое имя;
- фактическое число треугольников в mesh и metadata;
- распределения длин всех рёбер и площадей всех треугольников с допуском на
  безопасное округление Bambu Studio;
- выбранный режим supports;
- слой, стенки, верх/низ, brim, температуры и охлаждение;
- равенство SHA-256 встроенного и отдельного G-code.

## Реальная контрольная модель

Источник: `001.stl`, keycap-череп, 63478 треугольников, `READY`, watertight.
Профиль: Bambu Lab P1S 0.4, PLA, Textured PEI. Настройки результата: слой 0,16 мм,
3 стенки, 5/4 верхних/нижних слоя, auto brim, 220/55 °C, fan 100%.

| Стратегия | Время | Масса | Supports |
|---|---:|---:|---:|
| none | 1285,59 с | 4,78 г | 0,00 г |
| normal | 1406,67 с | 5,52 г | 0,74 г |
| tree | 1444,82 с | 5,32 г | 0,54 г |

Выбран `none`. Финальный проект содержит `model.oriented.stl`, а не Hulk.
Геометрия и G-code прошли все проверки. Дополнительно успешно пройден полный
pipeline с готовым keycap 3MF в роли исходной модели.
