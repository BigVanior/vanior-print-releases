# AI Print Optimizer — контрольная точка v1.2

Дата: 2026-08-23  
Статус: стабильный локальный релиз `1.2.0`

## Результат

Поверх проверенного ядра v1.1 создано полноценное Windows GUI-приложение. Пользователь
выбирает или перетаскивает STL/3MF, задаёт профиль и папку результата, а затем получает
проверенный 3MF и G-code без работы с консолью. Операции выполняются в отдельном потоке,
интерфейс остаётся отзывчивым, отображает этапы и поддерживает безопасную отмену.

GUI явно разделяет диагностику, безопасную автоматическую оптимизацию и прямую нарезку
исходного 3MF. Поэтому модель с неоднозначной топологией не ремонтируется молча, но
пользователь может осознанно сохранить исходную геометрию проекта.

## Проверки

- 48 unit/regression тестов, включая GUI-логику, прогресс и отмену;
- запуск Qt-окна через Windows backend и проверка кириллицы;
- реальный `001.stl`: `READY`, 20.23 × 23.31 × 27.60 мм;
- реальный Monster 3MF: четыре printable object, `REPAIR_RECOMMENDED`, без подмены;
- smoke-тест и анализ обоих реальных форматов через собранный Windows exe;
- onedir-дистрибутив с независимым `AI Print Optimizer.exe`.
