# AI Print Optimizer — контрольная точка v1.6.1

Дата: 2026-08-23  
Статус: стабильный локальный релиз `1.6.1`

## Исправление интерфейса

После завершения операции карточка результата увеличивала требуемую высоту окна,
а стандартный Qt layout уменьшал форму ниже её удобного размера. Из-за этого строки
модели, действия, назначения и принтера визуально обрезались.

Теперь всё содержимое находится в одной вертикальной области прокрутки. Поля имеют
минимальную высоту 30 px, результат — 190 px, журнал — 100 px. При нехватке места
появляется правая полоса прокрутки вместо сжатия элементов. После завершения она
автоматически переводит пользователя к итоговой карточке.

## Проверки

- завершённый экран воспроизведён в размере 975×918;
- фактическая высота поля модели — 32 px, карточки результата — 200 px;
- вертикальная прокрутка активируется, горизонтальная отключена;
- визуальный снимок проверен после отображения результата;
- 67 автоматических тестов успешно пройдены.
