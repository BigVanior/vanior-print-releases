# VANIOR PRINT v3.2.0 — объектная оптимизация STL/3MF

Дата: 2026-08-27.

## Что реализовано

- Печатаемые объекты выбранной пластины 3MF извлекаются в отдельные проверенные
  STL-снимки и одновременно в общий STL для контроля целостности стола.
- Значимые раздельные тела STL распознаются как самостоятельные модели. Мелкие
  декоративные оболочки присоединяются к ближайшему основному телу без удаления.
- Каждая модель отдельно проходит Geometry Intelligence, Functional Intent,
  Surface Intelligence и PrintDNA.
- Для каждого ID объекта независимо формируются высота слоя, стенки, верхние и
  нижние слои, заполнение, скорости, мосты, тонкие стенки, supports и локальные
  диапазоны по высоте.
- Исходные трансформации и положение моделей сохраняются. Настройки записываются
  в `Metadata/model_settings.config` на нативном объектном уровне Bambu Studio.
- После нарезки проверяются количество объектов, суммарная геометрия, число
  треугольников, все объектные параметры, отсутствие случайной многоцветности и
  совпадение встроенного и внешнего G-code по SHA-256.
- В интерфейсе результат содержит отдельную сводку для каждой модели.

## Проверки

- 104 автоматических теста: успешно.
- Полный конвейер обработал реальный `AllInOne_Upgrade.3mf` с 10 печатаемыми
  объектами: режим `object-specific-3mf-optimization`, один готовый 3MF и один
  G-code созданы, манифест записан.
- Независимая реальная нарезка Bambu Studio сохранила 10 объектов и разные
  объектные параметры; проверка готового проекта завершилась без ошибок.
- Полный маршрут STL с коробкой и сферой распознал две модели, назначил им разные
  слой и стенки, собрал один 3MF и успешно прошёл нарезку Bambu Studio.
