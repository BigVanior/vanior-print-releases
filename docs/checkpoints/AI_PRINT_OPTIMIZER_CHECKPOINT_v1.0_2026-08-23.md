# AI Print Optimizer — контрольная точка v1.0

Дата: 2026-08-23  
Статус: стабильный локальный релиз `1.0.0`

## Итог

AI Print Optimizer доведён от анализатора STL до воспроизводимого локального
pipeline для Bambu Lab P1S. Релиз анализирует и проверяет сетку, безопасно создаёт
исправленные/ориентированные/упрощённые копии, валидирует 3MF-профиль, запускает
Bambu Studio в изоляции, сравнивает supports, формирует проверяемый manifest и
обрабатывает каталоги с resume.

Стабилизированы:

- консольный интерфейс и коды завершения;
- публичные имена Python API;
- `schema_version = 1` для pipeline manifest и batch summary;
- запрет перезаписи входов и уже существующих результатов;
- атомарная публикация JSON, HTML и JSONL;
- wheel, sdist, исходный ZIP и Git bundle.

## Ограничения v1

- Физическая печать на принтере не запускалась: проверены геометрия, профили,
  Bambu Studio, G-code и расчётные метрики.
- Распознавание мостов и локальной толщины стенок остаётся функцией слайсера.
- Автоматическое упрощение намеренно отклоняет результат при любом нарушении
  топологии или заданных геометрических допусков.
- Поддерживаются P1S и материалы PLA/PETG; расширение списка является будущей
  функциональностью, а не частью контракта 1.0.

## Восстановление и установка

Wheel устанавливается командой:

```bash
python -m pip install ai_print_optimizer-1.0.0-py3-none-any.whl
ai-print-optimizer --self-check
```

Git bundle содержит полную ветку `main` и тег `v1.0.0`. Исходный ZIP предназначен
для переноса без Git. Контрольные SHA-256 всех релизных файлов опубликованы рядом
с артефактами.
