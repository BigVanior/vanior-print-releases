# AI Print Optimizer — контрольная точка v0.7

Дата: 23 августа 2026 года. Статус: валидируемые профили и безопасное упрощение.

## Реализовано

- проверка `printer_model`, `printer_settings_id`, `printer_technology`;
- проверка сопла, первого активного материала, стола и printable height;
- остановка pipeline до создания результатов при несовместимом профиле;
- квадратичное упрощение через `fast-simplification 0.1.13`;
- обязательные инварианты: `READY`, watertight, число тел, размеры, объём и площадь;
- автоматическая попытка упрощения сеток свыше 500000 треугольников;
- безопасное продолжение с оригиналом, если decimator нарушает инварианты;
- отдельные CLI-режимы `--validate-profile` и `--simplify-output`;
- профиль и решение об упрощении записываются в pipeline manifest;
- 31 автоматический тест.

## Реальная проверка Hulk

Профиль `Высокая(халк).3mf` подтверждён как P1S / 0,4 мм / PLA / Textured PEI.

Упрощение 576328 -> 345796 треугольников было отклонено до записи файла:
decimator создал неманифолдную сетку. Даже пробные сокращения на 5%, 10% и 20%
не прошли топологические инварианты. Pipeline сохранил исходную `WATERTIGHT` сетку.

Повторный A/B после проверки профиля:

```text
normal(auto): 18137,82 с / 151,81 г / supports 76,95 г
tree(auto):   13449,36 с / 100,62 г / supports 25,77 г
выбор: tree (-4688,5 с / -51,19 г)
```

Манифест v0.7: `valid=true`, проверено 10 файлов. Исходные STL/3MF не изменены.
