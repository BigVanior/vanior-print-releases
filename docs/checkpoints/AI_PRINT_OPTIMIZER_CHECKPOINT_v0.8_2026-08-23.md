# AI Print Optimizer — контрольная точка v0.8

Дата: 23 августа 2026 года. Статус: пакетная обработка и автономная отчётность.

## Реализовано

- рекурсивный и нерекурсивный поиск STL;
- детерминированные каталоги модели по имени и SHA-256;
- полный pipeline для каждой модели;
- продолжение batch после локальной ошибки модели;
- `--resume` с обязательной проверкой pipeline manifest;
- запрет перезаписи неполного или повреждённого результата;
- новый нумерованный summary/report при каждом resume;
- агрегированные время, масса и выбранный тип supports;
- автономный HTML с экранированием пользовательских имён и относительными ссылками;
- 33 автоматических теста.

## Реальная проверка

Batch из двух локальных моделей с профилем P1S / 0,4 мм / PLA:

```text
Porta_Filaccini_v1.stl
  completed, support-comparison, normal, 2304,73 с, 24,66 г

mini_scorpione.repaired.stl
  completed, support-comparison, tree, 1574,56 с, 6,31 г
```

Первый запуск: `completed=2`, `failed=0`. Повторный `--resume`: оба pipeline
manifest проверены, `skipped=2`, повторного слайсинга не было.

HTML проверен во встроенном браузере: заголовок v0.8.0, две строки, три карточки
сводки, корректные относительные ссылки, горизонтального переполнения на обычном
viewport нет. Локальный HTTP-сервер после проверки остановлен.
