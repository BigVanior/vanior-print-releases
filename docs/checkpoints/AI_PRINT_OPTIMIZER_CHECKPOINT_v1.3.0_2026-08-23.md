# AI Print Optimizer — контрольная точка v1.3.0

Дата: 2026-08-23  
Статус: стабильный локальный релиз `1.3.0`

## Главное изменение

Пользователю больше не требуется искать и выбирать проверенный 3MF-профиль.
Windows-приложение принимает STL или 3MF, а для полной оптимизации создаёт чистый
одноцветный профиль из официальных файлов установленного Bambu Studio.

Текущий поддерживаемый комплект: Bambu Lab P1S, сопло 0,4 мм, Textured PEI Plate,
PLA или PETG. Реестр разрешает цепочки `inherits` и `include`, поэтому в проект входят
официальные настройки машины, процесса, филамента, температуры, подачи, скорости,
ускорения и безопасный G-code принтера. В установленной версии Bambu Studio итоговый
профиль содержит 438 параметров из 16 системных JSON-файлов.

## Защита от чужой модели и цвета

Профиль создаётся с собственной служебной геометрией, которая затем полностью
заменяется обрабатываемой моделью. Не используются пользовательские объекты,
раскраска граней или диапазоны высоты из сторонних 3MF. Активен один чёрный слот
филамента; последующая проверка по-прежнему блокирует публикацию при обнаружении
нескольких фактически использованных материалов.
