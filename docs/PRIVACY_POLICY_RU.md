# Политика конфиденциальности VANIOR PRINT

Дата редакции: 10 сентября 2026 года.

VANIOR PRINT обрабатывает модели STL/3MF, G-code, настройки печати, историю
проектов и оценки PrintDNA локально на компьютере пользователя. По умолчанию
приложение не отправляет эти данные разработчику или рекламным системам.

Для прямой печати приложение соединяется только с указанным пользователем
локальным IPv4-адресом принтера. IP-адрес, серийный номер и SHA-256-отпечатки
сертификатов сохраняются локально. LAN access code существует только в памяти
запущенного процесса и не записывается в настройки, историю или диагностику.
Печатный файл передаётся непосредственно выбранному принтеру по локальной сети.

Необязательная синхронизация общего обучения PrintDNA выключена по умолчанию и
запускается только после явного включения и указания HTTPS-адреса сервиса. В неё
могут входить обезличенные параметры принтера, сопла, материала, настройки и
оценки результата. Модели, G-code, локальные пути, имена файлов, фотографии и
текстовые заметки не передаются.

Локальные данные обычной установки хранятся в каталоге VANIOR PRINT внутри
LocalAppData пользователя. Готовые файлы сохраняются в выбранную папку или в
«Загрузки». Пользователь может удалить их вручную или средствами приложения.

Приложение не содержит рекламы, не продаёт пользовательские данные и не создаёт
учётную запись без явного действия пользователя.
