# Выпуск VANIOR PRINT Public Beta

## Готовый технический контур

- самостоятельный VANIOR Slice без Bambu Studio и облачной авторизации;
- PyInstaller onedir без UPX и установщик Inno Setup с постоянным AppId;
- обновление поверх существующей версии без предварительного удаления;
- локальная прямая печать с закреплением сертификатов и повторной проверкой 3MF;
- автоматическое включение условий использования, политики и лицензий;
- сборка MSIX с проверкой структуры для будущей публикации в Microsoft Store.

## Перед внешней публикацией

1. Провести физическую серию тестов на P1S/0,4 мм отдельно для PLA и PETG:
   простой куб, мосты, обычные и древовидные поддержки, высокая модель.
2. Просмотреть каждый слой и сохранить фактические время, массу и дефекты.
3. Проверить установку, обновление и удаление на чистых Windows 10 и 11.
4. Подписать EXE доверенным Authenticode-сертификатом либо публиковать через
   Microsoft Store. Самоподписанный сертификат предупреждение SmartScreen не
   устраняет.
5. Опубликовать политику конфиденциальности на HTTPS-странице и проверить
   формулировки юристом применительно к рынкам продаж.
6. При коммерческом использовании сборщика установщика учесть актуальные условия
   Inno Setup; установленный компилятор 6.7.3 сообщает режим Non-commercial.

## Microsoft Store

Для Store нужны точные Identity Name и Publisher из Partner Center:

```powershell
$env:VANIOR_STORE_IDENTITY_NAME = "Package/Identity/Name"
$env:VANIOR_STORE_PUBLISHER = "Package/Identity/Publisher"
.\packaging\build_msix.ps1 `
  -PythonExecutable .\.venv\Scripts\python.exe `
  -StoreSubmission
```

Полученный пакет нужно проверить Windows App Certification Kit и отправить через
Partner Center. Локальный пакет с тестовой идентификацией не предназначен для
публичного распространения.

Техническая готовность не является юридическим заключением. Для коммерческого
релиза остаются обязательными физическая валидация профилей, выбранный канал
доверенной подписи и проверка применимого законодательства.
